## Cómo ejecutarlo
1. Base de datos: ejecutar evaluador_creditos.sql en MySQL. Crea la base, las tablas y el usuario inicial.
2. Contraseña de MySQL: definir la variable de entorno DB_PASS con la contraseña del usuario root en el sistema.
3. Conector: agregar Sistema_Evaluador/lib/mysql-connector-j-9.7.0.jar como librería del proyecto.
4. Ejecutar la clase EvaluadorDeCreditos.
